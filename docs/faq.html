Help centre

Common questions and quick fixes.

Troubleshoot permissions, checks, automation, profiles, and dashboard access.

Is Rallybit free?

Yes. All included bot and dashboard features are available to every server.

Why can’t I run a command?

Confirm that you have the configured staff role or Discord administrator permission, then check that the command is not temporarily disabled.

Why can’t members react?

Make sure Rallybit can view the channel, send messages, add reactions, and read message history.

Why did automation not post?

Check that automation is enabled, the selected channel still exists, and the bot has permission to post there.

Where are completed checks stored?

Open the server in the dashboard and select Audit logs.

Can I use a button instead of an emoji?

Yes. Change Participation mode in the server dashboard or use the matching slash command.

How do I change the winner count?

Set it in the dashboard or use /setwinners. The supported range is 1 to 100.

How do I remove Rallybit?

Remove the bot from your server through Discord’s member or integration settings. You can also ask support to delete retained server data.

Why does the dashboard show no servers?

Sign in with the Discord account that administers the server and confirm Rallybit has joined it.

Where do I report a bug?

Use the support server linked from the website or the /support command.
