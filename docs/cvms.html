Community Voice Moderation Services · Free beta

CVMS voice moderation

Local speech recognition flags configured phrases for staff review. CVMS is off until an admitted server configures it and every person in the selected voice channel gives informed consent.

The beta is review-only.A phrase match is not proof of misconduct. Staff must assess context before any warning, disconnection or temporary voice restriction. CVMS never issues automatic punishments.

1. Prepare the server

A Rallybit developer must run /cvms beta enabled:true in your server. Admission is free and does not start monitoring. Create a private staff case channel, hide it from @everyone, and check every other role that can read it.

/cvms setup log_channel:#cvms-cases enabled:true mode:manual threshold:75 retention_hours:24
/cvms channel action:add channel:General
/cvms rule action:add phrase:your restricted phrase

These commands require Manage Server. Rules are literal words or phrases, not regular expressions or a context-aware hate-speech classifier. Use them only for legitimate moderation; do not use CVMS to infer personal characteristics or target protected groups. Settings changes pause monitoring until staff explicitly starts a session.

2. Obtain individual consent

Each person in the voice channel must run the consent command, read the disclosure and press I agree for 24 hours. Administrators cannot consent for other people.

/cvms privacy
/cvms consent enabled:true

Consent is server-specific and expires after 24 hours. Changing excerpt-retention settings requires new consent. A session cannot start when any current participant has missing or expired consent.

3. Start and stop

/cvms start channel:General minutes:30
/cvms status
/cvms stop
/cvms consent enabled:false

Starting requires your configured warning role and Manage Messages. A notice is posted in the voice channel’s text chat before the receiver opens. Participants can stop the session using its button or withdraw consent. These opt-outs work during maintenance too. A new human joining pauses the session for a fresh consent check; moving, disconnecting or server-deafening Rallybit stops it. A deliberate stop stays paused until staff explicitly starts again.

4. Review cases

/cvms cases
/cvms review case_id:CASE_ID action:confirm
/cvms review case_id:CASE_ID action:dismiss

Possible matches create private cases containing a short excerpt, member, channel, approximate recognition score and expiry. The score concerns transcription, not whether a violation occurred. Mark reviewed only after assessing context. Reviewed cases offer human-operated Warn member, Disconnect and Restrict this VC (10m) controls. A reason is required; disconnection and restriction require typed confirmation.

Existing moderation-role checks and actor/bot hierarchy apply. Restriction also needs the configured timeout permission, Move Members and Manage Channels. It changes only the member’s Connect overwrite in that voice channel, then restores its previous value without overwriting unrelated permissions.

Dismissal removes the retained excerpt. Case excerpts expire after 1–24 hours. Associated Discord log messages are deleted where the bot still has access; otherwise server staff must delete them. Independent screenshots, archives, ordinary moderation records and manually submitted reports have their own retention practices.

5. Watches and voice reports

/cvms watch action:add member:@member minutes:60 reason:Recent voice incident
/cvms watch action:list
/cvms watch action:remove member:@member
/cvms reports enabled:true
/cvms report member:@member reason:Describe the incident
/report user member:@member reason:Describe the incident voice:true

Watch mode considers time-limited watched members. A voice report must concern someone in the reporter’s current configured channel. Reports request a short eligible session, are rate limited, are not proof of misconduct, and cannot bypass consent. Watch/report sessions process selected consenting members only and never exceed the watch/report expiry. Enable the appropriate mode through Setup, then explicitly Start to resume after configuration changes.

Coverage and accuracy limits

  • One monitored channel per server, up to two sessions across this instance, and two simultaneous speaker streams per session.
  • Local inference handles one request at a time with a bounded queue. Overload drops clips rather than building a recording backlog. Other configured channels are not simultaneously covered.
  • English only in this beta. Noise, accents, music, quotations and overlapping speech can cause missed or false matches. Human context review is essential.
  • Raw clips are at most eight seconds, processed locally in memory, and not saved as recordings or sent to external AI services. There is no conversation-wide transcript or model training.
  • Platform changes can break Discord voice receiving. CVMS is not an emergency service or a replacement for human moderation.

Self-hosting

Start the optional local engine with docker compose -p rallybit-js -f bot-js/compose.yaml --profile cvms up -d --build. It uses pinned whisper.cpp and an integrity-checked English model on an isolated internal network, with one CPU core, limited memory and no persisted inference logs. No API key, paid plan or external inference account is required. Your existing machine still uses electricity, storage and bandwidth; processing capacity is not unlimited.

Review your applicable privacy and recording obligations before enabling the feature. Consent controls do not guarantee legal compliance. Read the privacy policy and terms.
