How slash commands work

1

Choose the command

Type / in a server channel, select Rallybit, then choose the command or subcommand you need.

2

Complete its options

Discord shows every field in order. Options marked Required must be completed; optional fields can be left empty.

3

Choose reply visibility

Replies are public by default. Set private:true to make Rallybit's command response visible only to you.

Commands only appear when Discord allows them. If a command is missing, confirm the required server permission or configured Rallybit role shown in its guide. The bot must also have permission to carry out the requested action.
