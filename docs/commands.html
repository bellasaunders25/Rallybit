Command reference · Build 7.2.2

Every Rallybit command, organised by job.

Type / in Discord, choose Rallybit, and Discord will show the commands your current permissions allow you to use.

Slash-command control.Normal features remain slash-command driven. Message Content Intent is used only when optional security filtering or message-event logging is enabled.

Activity checks

/activitycheck

Start a timed activity check in the current channel.

/endactivitycheck

Stop the active check and publish the result.

/setactivitytext

Change the message used by new checks.

/setmode

Switch between emoji reaction and interactive button mode.

/setreactor

Choose the participation emoji.

/setbuttontext

Change the participation button label.

/setwinner

Choose the participant target, up to 100.

/setduration

Set the default check duration, from 1 to 1,440 minutes.

/setperm

Choose the staff role allowed to start and stop checks.

/setlogs

Choose where check and moderation logs are posted.

/setauto

Configure the recurring activity-check channel and interval.

/startauto / /stopauto

Resume or pause recurring activity checks.

Community quizzes

/quiz start

Start a random timed quiz. Staff can optionally notify the configured quiz role with notify_role:true.

/quiz stop

End the active quiz and reveal its answer and results immediately.

/quiz setup

Choose the automatic quiz channel, interval, category, answer time, and optional chat-revive role ping.

/quiz auto

Enable or pause recurring automatic quizzes.

/quiz pingrole

Set the role used by automatic quizzes and optional manual quiz notifications, or run it without a role to disable pings.

/quiz settings

Review the server's automatic quiz configuration.

/quiz leaderboard

Rank members by quiz points, accuracy, and streak performance.

Community tools

/community icebreaker

Post a random conversation starter. Staff can use notify_role:true to ping the configured Chat Revive role.

/community pulse

Start an anonymous aggregate mood pulse. It notifies the configured community role by default; use notify_role:false for a silent pulse.

/community pingrole

Set the role used by community pulse notifications and staff-triggered icebreakers, or leave the role empty to disable it.

/community settings

Review the configured community notification role and default behaviour.

/community stoppulse

Close the active pulse and publish its aggregate result.

/community pulsehistory

View aggregate trends from the last ten completed pulses. Individual responses are not stored in history.

/afk

Set yourself as AFK with an optional reason. Members who mention you are told that you are away, and the status is removed when you next send a message.

Reviews

/review type user stars reason

Submit a one-to-five-star review for a staff member or community member. Staff reviews and member reviews are routed to their separately configured dashboard channels.

Moderation

/channel transcript

Authorized moderation staff can archive every available message from a selected text channel into another text channel or a new forum post. The archive records the source channel name, archive time, staff member, message IDs, timestamps, edits, replies, attachments, stickers, embeds, reactions, and message links.

/channel purge

Authorized moderation staff can delete an inclusive range using its first and last message IDs, delete all messages from a selected member with an optional amount cap, or delete the latest chosen amount. Message links may be supplied instead of raw IDs, and an optional reason is written to Discord's audit log.

/mod panel

Open the interactive member panel with warnings, timeout controls, kick, ban, message clearing, nickname changes, and role tools.

/mod warn

Add a warning with a unique warning ID and an audit entry.

/mod warnings

View a member's active Rallybit warnings.

/mod unwarn

Remove a warning by ID or remove the latest active warning.

/mod unban

Unban a Discord user by numeric user ID.

/role give / /role remove

Give or remove a role only when both the acting moderator and Rallybit are above the selected role and target member. Managed roles and @everyone are rejected.

/role temp

Assign a persistent temporary role for days, weeks, 30-day months, or 365-day years. Rallybit appends a compact live countdown to the member's nickname, accepts an optional base nickname, survives restarts, and restores the original nickname after the member's final temporary role expires.

/report user

Privately report a member with a reason, optional details, and an evidence link. The report is sent to the configured moderation review channel.

/report status

View the current status, assigned staff member, and latest update for a report you submitted.

/report settings

Staff only. Choose the moderation channel that receives new member reports.

/report list

Staff only. View reports that are pending, claimed, or under review.

/report claim

Staff only. Assign yourself to a report so other moderators can see who is handling it.

/report setstatus

Staff only. Change a report to Pending, Claimed, Under Review, Resolved, Dismissed, or Closed and optionally add an update.

/report close

Staff only. Close a report with an optional resolution note.

/report reopen

Staff only. Return a previously closed report to the moderation review queue.

/report history

Staff only. View reports that have been submitted against a particular member.

Tickets

/ticket create

Create a support ticket in a configured ticket category and provide the reason for the request.

/ticket status

View whether the current ticket is Open, Claimed, Pending, Waiting for User, Resolved, or Closed, together with its priority and assigned staff member.

/ticket close

Close and lock the current ticket with a required reason. The Close button opens the same reason form, and a transcript is sent to the configured log channel.

/ticket reopen

Staff only. Reopen a closed ticket, restore the owner's access, and return its status to Open.

/ticket claim

Ticket support staff only. Assign the current ticket to yourself using the configured support role or native Manage Messages permission.

/ticket unclaim

Staff only. Remove the current staff assignment and return the ticket to the unassigned queue.

/ticket priority

Staff only. Set the ticket priority to Low, Medium, High, or Critical.

/ticket setstatus

Staff only. Move the ticket through Open, Claimed, Pending, Waiting for User, Resolved, or Closed.

/ticket transcript

Generate a text transcript of the current ticket before or after it is closed.

/ticket settings

Staff only. Configure the default category, support role, log channel, transcript limit, automatic deletion delay, and one-ticket-per-member rule.

/ticket panel create

Publish one persistent dropdown panel with a first ticket type, custom icon, description, placeholder, header image, thumbnail, body image, author, footer text/icon, and optional workload or guidance sections.

/ticket panel add-option / remove-option

Add up to 25 named dropdown choices, each with its own description, custom Unicode or server emoji, destination category, and support role, without republishing the panel.

/ticket panel list / delete

Inspect or remove configured ticket dropdowns. Existing Rallybit button panels are migrated to a compatible one-option dropdown when the bot refreshes them.

Ticket control buttons

Configured support staff can claim, export, close, or permanently delete a ticket. Claim announcements are pinned automatically, and deletion requires confirmation and archives a final transcript.

/ticket add / remove / rename

Staff only. Manage ticket participants or rename the current ticket channel.

Security

/security overview

Review every security module, threshold, trusted-role bypass, log channel, account age gate, and scam trap setting.

/security-trap setup

Create or repair the top-level #do-not-text-here honeypot. Human accounts that post there are immediately banned or kicked according to the server setting.

/security-agegate configure

Kick accounts younger than a configurable number of days after attempting to DM the server rule and appeal link.

/security-antibot configure

Ban unauthorised bot additions and apply the chosen action to the account that added the bot.

/security-modules set

Enable anti-webhook, anti-integration, anti-dangerous-permission, and anti-nuke modules with ban, kick, or quarantine actions.

/security-modules threshold

Choose how many bans, kicks, channel deletions, role deletions, emoji deletions, or sticker deletions trigger protection within a time window.

/security-antispam configure

Set a rapid-message limit, time window, and automatic timeout length.

/security-automod ...

Optionally block Discord invites and maintain a per-server word or phrase filter.

/security-trust ...

Add trusted roles, remove them, list bypasses, or choose whether all administrators bypass automatic protection.

/security-logs ...

Set the security-alert channel, enable optional member/message/voice/structure logs, and optionally DM the server owner after automatic actions.

/security audit / /security history

Scan the server for permission weaknesses and review persistent security events.

/security lockdown / /security panic

Disable basic @everyone chat and voice permissions, restore the saved state, or combine lockdown with an emergency invite purge.

/security quarantine / /security release

Strip manageable roles, isolate a member, and later restore roles saved by Rallybit.

/security clearinvites / /security purgeuser

Delete active invites or perform a confirmation-protected soft-ban message purge.

Permission notes

Regular members can use profiles, leaderboards, quiz rankings, AFK, icebreakers, ticket creation, reviews, report submission, and help commands. Review destinations are configured in Dashboard → Control Center → Reviews. Staff report actions use the Warnings and Reports permission configured in Dashboard → Control Center → Moderation. Ticket staff actions accept the configured ticket support roles as well as administrators and members with Manage Messages. The moderation panel shows only the actions its moderator is allowed to use and checks both the moderator and bot role hierarchy before applying them.
